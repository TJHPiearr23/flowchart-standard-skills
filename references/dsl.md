# spec.json 完整参考

渲染器 `scripts/flowchart.py` 的输入是一份 JSON。坐标**不需要写**——由网格布局自动计算；只有在极少数需要人工干预时才用 `row` / `col`。

## 1. 顶层字段

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `title` | string | — | 图标题 |
| `subtitle` | string | — | 副标题；学术版可直接写成图题「图 1　xxx」（默认居中排在图上方） |
| `style` | `"academic"` \| `"color"` | `"academic"` | **学术黑白**：白底黑线、开口箭头、直角框、无图例；**彩色**：按符号类别着色、带图例 |
| `theme` | `"light"` \| `"dark"` \| `"auto"` | `"light"` | 仅 `style:"color"` 时生效；academic 恒为白底 |
| `start_shape` | `"hexagon"` \| `"stadium"` | `"hexagon"` | 开始符号形状。hexagon＝准备作业（ISO 默认）；stadium＝部分教材的圆角矩形起止 |
| `show_legend` | bool | academic `false` / color `true` | 底部图例行；对外评审的独立插图建议关闭 |
| `fragment` | bool | `false` | 片段模式：画跨页的「半张流程图」时置 `true`，跳过入口/出口/可达性检查 |
| `nodes` | array | 必填 | 节点列表，顺序即同层左右顺序 |
| `edges` | array | 必填 | 连线列表，顺序决定分支的左右次序 |
| `notes` | array | `[]` | 批注 |

## 2. 节点 node

```json
{"id": "d1", "type": "decision", "text": "密码正确？"}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一标识，供 `edges` 引用，建议语义化（`d1`、`p_check`） |
| `type` | 是 | 见符号表：`start` `end` `process` `decision` `document` `predefined` `io` `connector_in` `connector_out` `junction` |
| `text` | 是 | 框内文字。处理≤12 字动词短语；判定写问句带「？」；连接符只写编号 |
| `row` / `col` | 否 | 手动布局，**两者同时给出**才生效；只要有一个节点没给，全图改用自动布局 |

## 3. 连线 edge

```json
{"from": "d1", "to": "p2", "label": "否", "back": false, "style": "solid"}
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `from` / `to` | 必填 | 节点 id |
| `label` | 空 | 菱形出边**必须**填：是/否/Y/N/条件值/默认 |
| `back` | `false` | 回流边（循环折返）。自动识别，但**显式写更稳** |
| `style` | `"solid"` | `"dashed"` 用于回流或弱化的辅助线 |

## 4. 批注 note

```json
{"text": "最多 3 次重试，超限锁定 15 分钟。", "near": "d2"}
```

`near` 指定锚点节点。渲染器按「右侧 → 上下避让 → 左侧 → 下方」顺序找空位；四处都被占时自动落到图底「批注区」，并在文字前加 `〔锚点文字〕`，保证不压线、不压框。

## 5. 自动布局规则（为什么不用手写坐标）

1. **分层**：从 `start` 出发做最长路径分层，一层一行。回流边不参与分层。
2. **分列**：主干恒在第 0 列；判定的旁路分支向右展开（是 → 同列向下，否 → 右移一列）；多路分支按 `edges` 中的书写顺序依次占 0,1,2… 列。
3. **回汇**：同一目标的多条汇入边自动错开入口，避免箭头叠在一起。
4. **连线**：只走横竖。向下直连；向右绕行从右侧出口进入目标顶部；向左回汇从目标**右侧**进入，避免横穿主干竖线。
5. **避让**：横段若会压到同层其他符号，自动改成「贴右缘下行 → 行间空隙横移 → 下折入顶」的台阶路径，绝不从方框背后穿过。
6. **跳线**：不可避免的交叉自动画「小半圆跨线」，并在校验里报 E20 提示具体条数。
7. **尺寸**：同类符号尺寸全局统一（宽度 176），行高按该行最高符号取齐。

## 6. 命令行

```bash
python scripts/flowchart.py spec.json                    # 生成同名 .html
python scripts/flowchart.py spec.json -o 图.html --svg 图.svg
python scripts/flowchart.py spec.json --check            # 只校验不落盘
python scripts/flowchart.py spec.json --check --strict   # 有 E 级问题返回码 1
```

- 输出 HTML 是自包含单文件（内联 SVG + CSS 变量），可直接浏览器打开、打印成 PDF、截图贴文档。
- `--svg` 额外导出矢量图，方便插进 Word/PPT。

## 7. 校验码表

| 码 | 级别 | 含义 | 处理 |
|---|---|---|---|
| E01 | 错误 | 开始节点缺失或多于一个 | 补/删 start |
| E02 | 错误 | 缺结束节点 | 补 end |
| E04 | 错误 | 连线引用了不存在的节点 id | 改 id |
| E05 | 错误 | 节点没有出口（流程中断） | 补连线，或改类型为 end / connector_out |
| E06 | 错误 | 判定少于 2 条出边 | 补分支 |
| E08 | 错误 | 判定分支未标注 | 补 是/否/条件值 |
| E09 | 错误 | 判定的出口全是回流 → 死循环 | 补终止出口 |
| E18 | 错误 | 开始节点有入边 | 删掉入边 |
| E19 | 错误 | 结束节点有出边 | 删掉出边 |
| E07 | 提示 | ≥3 分支但无「默认」兜底 | 补默认分支 |
| E10 | 提示 | 节点从入口不可达 | 接线或删除 |
| E12 | 提示 | 判定文字未以「？」结尾 | 改成问句 |
| E16 | 提示 | 节点文字为空 | 补文字 |
| E20 | 提示 | 存在交叉（已画跳线） | 调分支顺序或拆图 |
| W02 | 提示 | 结束节点 >2 | 收敛出口 |
| W11 | 提示 | 文字超过该符号可容纳行数 | 压缩文字 |
| W13 | 提示 | 节点文字 >16 字 | 压成短语 |
| W14 | 提示 | 识别到未标注的回流边 | 显式写 `"back": true` |

`--strict` 只对 E 级返回非零，W 级不阻断交付。
