# 标准符号表（ISO 5807 / GB 1526）

流程图只认符号语义，不认好看。选错形状 = 逻辑表意错误，比画歪更严重。

## 一、符号对照

| 形状 | 名称 | 语义 | DSL `type` | 使用场合 | 文字规范 |
|---|---|---|---|---|---|
| 六边形 | 准备作业 / Start | 流程图开始 | `start` | 全图唯一入口 | 固定写「开始」 |
| 矩形 | 处理 / Process | 执行一个动作 | `process` | 一切计算、赋值、保存、调用 | 动词短语，≤12 字，如「校验密码」 |
| 菱形 | 决策 / Decision | 多方案选择 | `decision` | 需要判断后再分流 | 必须是问句，以「？」结尾，如「密码正确？」 |
| 圆角矩形（或椭圆） | 终止 / END | 流程结束 | `end` | 出口；可 1~2 个 | 固定写「结束」/「流程终止」 |
| 单向箭头 | 路径 / Path | 流向 | `edges` | 全部连线 | 菱形出边必须标注 |
| 底边波浪矩形 | 文件 / Document | 输入或输出文件（纸质/单据/报表） | `document` | 生成或读取一份文档 | 名词短语，如「采购审批单」 |
| 左右双竖线矩形 | 已定义处理 / Predefined Process | 调用另一处已定义的处理程序 | `predefined` | 调用子流程、外部系统、公共函数 | 「XX 子流程」「调用 XX」 |
| 圆形 | 连接 / Connector（入口） | 从别处进入本页 | `connector_in` | 跨页续接的起点 | 单个编号，如 `A` |
| 五边形（向下指） | 连接 / Connector（出口） | 本页转向另一页 | `connector_out` | 跨页续接的终点 | 与入口同编号 |
| 平行四边形 | 输入 / 输出 | 手工输入数据或输出结果 | `io` | 键盘录入、屏幕打印、接口收发 | 「输入 XX」「输出 XX」 |
| 虚线框 + 虚线引出线 | 批注 / Comment | 附注说明，不参与流程 | `notes` | 补充口径、例外、取值说明 | 完整句子，可长 |
| 小圆点 | 汇合点 / Junction | 多条支路收敛为一条 | `junction` | 分支太多、汇合线打架时 | 无文字 |

## 二、易混符号的取舍

1. **矩形 vs 文件**：动作是「处理数据」用矩形；产出或读取一张单据、报表、文件用文件。写「生成报表（文件）」但画成矩形是常见错误。
2. **矩形 vs 已定义处理**：逻辑在本图内展开用矩形；本图不展开、只引用别处的处理（子流程/外部系统）用已定义处理。
3. **平行四边形 vs 矩形**：与人或外部系统交换数据用平行四边形；纯内部计算用矩形。
4. **连接符 vs 箭头**：同一页内不要用连接符「跳过」空间，连接符只用于跨页或跨图。
5. **判定 vs 多分支**：只有两种结果用菱形两出口；三种以上并列结果仍用一个菱形，但必须含「默认」分支。

## 三、视觉风格（默认学术黑白）

| 风格 | 适用 | 特征 |
|---|---|---|
| `academic`（默认） | 论文、毕设、评审文档、印刷 | 纯白填充 + 1.25px 黑色描边 + 开口细线箭头 + 直角框 + 无图例 + 标题居中 |
| `color` | 汇报 PPT、方案演示、需要快速扫读分类 | 按符号类别填充浅色（绿/蓝/黄/青/紫/红/灰），实心箭头，带图例 |

学术黑白的着色原则只有一条：**不填色**。用符号形状和线宽区分元素，不用颜色区分——因为黑白打印、灰度复印、期刊排版都会丢失颜色信息。

需要彩色版时在 spec 顶层加 `"style": "color"`（可再配 `"theme": "light"|"dark"`）。同一份 spec 两种风格都能用，切换只改一行。
